Notes
- Upload the STEP files if the bureau accepts them; STLs are the same geometry.
- Wall rule is 1.0 mm everywhere (conservative for metal). Raised crown logo detail is held to 0.4 mm; check this against the bureau's minimum embossed feature (cast processes usually need 0.4-0.5 mm).
- Metal needs finishing allowance: ask for polished contact faces and keep bayonet clearances under review after a first test part. Nothing has been tolerance-tuned for metal.
- A metal RingBase touches the Carrier. Keep it electrically isolated from the pogo pins, or add an insulating liner, before using it as a circuit return. Plate any contact face (nickel or gold) to avoid galvanic corrosion.
- `manifest.json` holds volumes, wall checks and indicative price ranges (generic industry figures, not a quote). Minimum order values will dominate at this size.
